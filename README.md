# Softdock demo

A software download directory built on WordPress.

**[Open the live demo](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/sksohan1998/softdock-demo/main/blueprint.json)**

The demo runs entirely in your browser using WordPress Playground. It takes about 30 seconds to load. You are signed in as the site admin, so you can also open the dashboard (top-left W menu) and try adding or editing programs.

Every visit starts fresh, and nothing you change is saved. The programs shown are examples.
